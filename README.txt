 - The server should be set up with port forwarding on the selected port, or you can use a program such as playit to send data.
   To be compatible with playit (as of 2026) the server uses UDP.
   Client connects to the server with the IP and port provided in config.ini
   Server creates players.db file to save stats.
   The scoreboard connects via a code, which allows for multiple games and scoreboards connected to the server at once.
   The games played are saved in the database through a session name.
